═══════════════════════════════════════════════════════════════════

🚀 METHOD 1: AUTOMATIC UPLOAD (EASIEST!)

Step 1: Get Your Repository URL
   1. Go to your forked repository on GitHub
   2. Click the green "Code" button
   3. Copy the HTTPS URL
   Example: https://github.com/yourusername/inventory-system.git

Step 2: Run Upload Script
   1. Double-click "git_upload.bat" file
   2. Paste your repository URL when asked
   3. Press Enter
   4. Enter GitHub credentials if asked
   5. Wait for upload to complete

Step 3: Verify
   1. Go to your GitHub repository
   2. Refresh the page
   3. All files should be there!

═══════════════════════════════════════════════════════════════════

🖱️ METHOD 2: GITHUB DESKTOP (VISUAL)

Step 1: Install GitHub Desktop
   Download from: https://desktop.github.com/

Step 2: Add Repository
   1. Open GitHub Desktop
   2. File → Add Local Repository
   3. Browse to: C:\xampp\htdocs\inventory-system
   4. Click "Add Repository"

Step 3: Publish
   1. Click "Publish repository"
   2. Choose your forked repository
   3. Click "Publish"
   4. Done!

═══════════════════════════════════════════════════════════════════

💻 METHOD 3: COMMAND LINE (MANUAL)

Step 1: Open Command Prompt
   1. Go to: C:\xampp\htdocs\inventory-system
   2. Type "cmd" in address bar
   3. Press Enter

Step 2: Run These Commands
   
   git init
   
   git remote add origin https://github.com/YOUR-USERNAME/REPO-NAME.git
   
   git add .
   
   git commit -m "Initial commit: Inventory Management System"
   
   git push -u origin main

Step 3: Enter Credentials
   - Username: Your GitHub username
   - Password: Personal Access Token (not password!)

═══════════════════════════════════════════════════════════════════

🌐 METHOD 4: WEB UPLOAD (NO GIT NEEDED)

Step 1: Prepare Files
   1. Go to: C:\xampp\htdocs\inventory-system
   2. Select all files and folders
   3. Right-click → Send to → Compressed folder
   4. Name it: inventory-system.zip

Step 2: Upload to GitHub
   1. Go to your forked repository
   2. Click "Add file" → "Upload files"
   3. Drag and drop the ZIP file
   4. Or click "choose your files" and select all
   5. Add message: "Initial commit"
   6. Click "Commit changes"

Step 3: Done!
   Files will be uploaded to GitHub

═══════════════════════════════════════════════════════════════════

🔑 GITHUB PERSONAL ACCESS TOKEN

If you need to create a token:

1. Go to GitHub.com
2. Click your profile picture → Settings
3. Scroll down → Developer settings
4. Personal access tokens → Tokens (classic)
5. Generate new token (classic)
6. Give it a name: "Inventory System Upload"
7. Select scopes: ✓ repo (all)
8. Click "Generate token"
9. COPY THE TOKEN (you won't see it again!)
10. Use this token as password when pushing

⚠️ COMMON ISSUES:

Problem: "Git is not installed"
Solution: Download from https://git-scm.com/download/win

Problem: "Authentication failed"
Solution: Use Personal Access Token, not password

Problem: "Remote origin already exists"
Solution: Run: git remote remove origin
         Then try again

Problem: "Failed to push"
Solution: Run: git pull origin main --allow-unrelated-histories
         Then: git push -u origin main
