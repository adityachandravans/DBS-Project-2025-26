========================================
XAMPP INSTALLATION GUIDE
========================================

STEP 1: Install XAMPP
----------------------
Download from: https://www.apachefriends.org/
Install and remember the installation directory.

STEP 2: Copy Project Files
---------------------------
Copy this entire project folder to:
  Windows: C:\xampp\htdocs\
  Mac: /Applications/XAMPP/htdocs/
  Linux: /opt/lampp/htdocs/

Your project should be at: C:\xampp\htdocs\[project-folder-name]\

STEP 3: Start XAMPP
--------------------
1. Open XAMPP Control Panel
2. Click "Start" for Apache
3. Click "Start" for MySQL
4. Both should show green "Running" status

STEP 4: Create Database
------------------------
METHOD 1 - Using phpMyAdmin (Recommended):
1. Open browser: http://localhost/phpmyadmin
2. Click "Import" tab at the top
3. Click "Choose File" button
4. Select "database.sql" from this project folder
5. Click "Go" button at the bottom
6. You should see "Import has been successfully finished"

METHOD 2 - Manual Creation:
1. Open browser: http://localhost/phpmyadmin
2. Click "New" on the left sidebar
3. Database name: inventory_db
4. Click "Create"
5. Click on "inventory_db" database
6. Click "SQL" tab
7. Open database.sql file in notepad
8. Copy all content and paste in SQL box
9. Click "Go"

STEP 5: Access Application
---------------------------
Open browser and go to:
  http://localhost/[your-project-folder-name]/

Example: http://localhost/inventory-system/

STEP 6: Register & Login
-------------------------
1. You'll be redirected to login page
2. Click "Register here" link
3. Fill in:
   - Username: your name
   - Email: your email
   - Password: your password
   - Confirm Password: same password
4. Click "Register"
5. After success, click "Login here"
6. Enter your email and password
7. Click "Login"
8. You're in! Start managing inventory.

========================================
TROUBLESHOOTING
========================================

Problem: "Connection failed" error
Solution:
- Make sure MySQL is running (green in XAMPP)
- Check config/db.php file
- Default settings should be:
  Host: localhost
  User: root
  Password: (empty)
  Database: inventory_db

Problem: "Page not found" or 404 error
Solution:
- Check Apache is running (green in XAMPP)
- Verify project is in htdocs folder
- Check URL spelling
- Try: http://localhost/

Problem: "Database not found"
Solution:
- Import database.sql again
- Or manually create database named: inventory_db

Problem: Blank white page
Solution:
- Check Apache error logs in XAMPP
- Enable error display in php.ini
- Check file permissions

Problem: Port 80 already in use
Solution:
- Close Skype or other programs using port 80
- Or change Apache port in XAMPP config
