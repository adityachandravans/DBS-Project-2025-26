🎯 IMMEDIATE FIX (3 STEPS):

Step 1: CHECK IF MYSQL IS RUNNING
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Open XAMPP Control Panel                                │
   │ 2. Look at MySQL row                                        │
   │ 3. Should say "Running" in GREEN                            │
   │ 4. If not, click "Start" button                             │
   └─────────────────────────────────────────────────────────────┘

Step 2: IMPORT DATABASE
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. In XAMPP, click "Admin" next to MySQL                    │
   │ 2. This opens phpMyAdmin                                    │
   │ 3. Look for database "inventory_db" on left side            │
   │ 4. If it doesn't exist:                                     │
   │    - Click "New" at top                                     │
   │    - Name: inventory_db                                     │
   │    - Click "Create"                                         │
   │ 5. Click on "inventory_db"                                  │
   │ 6. Click "Import" tab at top                                │
   │ 7. Click "Choose File"                                      │
   │ 8. Select "database.sql" from your project folder           │
   │ 9. Click "Go" at bottom                                     │
   │ 10. Wait for green success message                          │
   └─────────────────────────────────────────────────────────────┘
