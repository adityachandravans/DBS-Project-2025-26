🔧 IF SOMETHING GOES WRONG:

Problem: Page doesn't redirect
Solution: Visit debug_registration.php and use test form

Problem: Database error
Solution: 
   1. Start MySQL in XAMPP
   2. Visit http://localhost/phpmyadmin
   3. Import database.sql
   4. Try again

Problem: Can't see OTP
Solution: Look for YELLOW warning box on verify_otp.php

Problem: Invalid OTP
Solution: 
   - Copy OTP exactly from yellow box
   - Make sure it hasn't expired (10 min)
   - Click "Resend OTP" to get new one
