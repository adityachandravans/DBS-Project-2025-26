========================================
⚡ QUICK START GUIDE
========================================

Get your Inventory Management System running in 5 minutes!

========================================
STEP 1: XAMPP SETUP (2 minutes)
========================================

1. Install XAMPP from: https://www.apachefriends.org/
2. Copy this project folder to: C:\xampp\htdocs\
3. Open XAMPP Control Panel
4. Start Apache (click Start button)
5. Start MySQL (click Start button)
6. Both should show green "Running" status

========================================
STEP 2: DATABASE SETUP (1 minute)
========================================

1. Open browser: http://localhost/phpmyadmin
2. Click "Import" tab
3. Click "Choose File"
4. Select "database.sql" from this folder
5. Click "Go" button
6. Wait for "Import successful" message

========================================
STEP 3: EMAIL SETUP (1 minute)
========================================

Edit: C:\xampp\php\php.ini
Add these lines:
---
SMTP=smtp.gmail.com
smtp_port=587
---

Edit: C:\xampp\sendmail\sendmail.ini
Add these lines:
---
smtp_server=smtp.gmail.com
smtp_port=587
auth_username=seminarmanagement143@gmail.com
auth_password=atkiotfaccnmpiql
force_sender=seminarmanagement143@gmail.com
---

Restart Apache in XAMPP!

========================================
STEP 4: TEST & RUN (1 minute)
========================================

1. Open: http://localhost/[your-folder-name]/test_connection.php
2. Verify all tests pass ✓
3. Open: http://localhost/[your-folder-name]/test_email.php
4. Send test email to your email
5. Check inbox (and spam folder)

========================================
STEP 5: START USING! (30 seconds)
========================================

1. Open: http://localhost/[your-folder-name]/
2. Click "Register here"
3. Fill in your details
4. Check email for OTP
5. Enter OTP to verify
6. Login and start managing inventory!

========================================
⚠️ COMMON ISSUES & FIXES
========================================

Issue: Apache won't start
Fix: Close Skype, it uses port 80

Issue: MySQL won't start
Fix: Stop other MySQL services

Issue: Page not found
Fix: Check folder name in URL

Issue: Database error
Fix: Import database.sql again

Issue: Email not sending
Fix: Check php.ini and sendmail.ini
     Restart Apache after changes

Issue: OTP not received
Fix: Check spam folder
     Test with test_email.php
     Verify email configuration
