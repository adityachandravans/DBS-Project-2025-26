========================================
HOW IT WORKS
========================================

1. USER REGISTRATION:
   - User fills registration form
   - System generates 6-digit OTP
   - OTP is saved in database with 10-minute expiry
   - Email sent to user with OTP
   - User redirected to OTP verification page

2. OTP VERIFICATION:
   - User enters 6-digit OTP
   - System validates OTP and expiry time
   - If valid: account verified, welcome email sent
   - If invalid: error message shown
   - User can resend OTP if needed

3. LOGIN:
   - Only verified users can login
   - Unverified users see error message
   - After verification, user can access dashboard

XAMPP EMAIL CONFIGURATION
========================================

To send emails from XAMPP, you need to configure PHP:

STEP 1: Edit php.ini
Location: C:\xampp\php\php.ini

Find and update these lines:

[mail function]
SMTP=smtp.gmail.com
smtp_port=587
sendmail_from=seminarmanagement143@gmail.com
sendmail_path="\"C:\xampp\sendmail\sendmail.exe\" -t"

STEP 2: Edit sendmail.ini
Location: C:\xampp\sendmail\sendmail.ini

Update these lines:

smtp_server=smtp.gmail.com
smtp_port=587
auth_username=seminarmanagement143@gmail.com
auth_password=atkiotfaccnmpiql
force_sender=seminarmanagement143@gmail.com

STEP 3: Restart Apache
- Stop Apache in XAMPP Control Panel
- Start Apache again

========================================
TROUBLESHOOTING
========================================

Problem: Email not sending
Solutions:
□ Check internet connection
□ Verify SMTP settings in php.ini
□ Verify sendmail.ini configuration
□ Restart Apache after config changes
□ Check if Gmail account allows less secure apps
□ Verify app password is correct
□ Check spam folder

Problem: "Failed to send OTP email"
Solutions:
□ Check PHP mail() function is enabled
□ Verify sendmail is configured
□ Check Apache error logs
□ Test with a simple mail() script first

Problem: OTP expired
Solutions:
□ Click "Resend OTP" button
□ New OTP will be sent with fresh 10-minute timer
□ Check email and enter new OTP

Problem: Invalid OTP error
Solutions:
□ Make sure you entered all 6 digits
□ Check for typos
□ Request new OTP if needed
□ OTP is case-sensitive (numbers only)
