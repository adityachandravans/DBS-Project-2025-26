========================================
XAMPP SETUP CHECKLIST
========================================

Follow this checklist to ensure everything is set up correctly:

□ STEP 1: XAMPP Installation
   □ Downloaded XAMPP from apachefriends.org
   □ Installed XAMPP successfully
   □ Know the installation directory (usually C:\xampp)

□ STEP 2: Copy Project
   □ Copied entire project folder to htdocs
   □ Path is: C:\xampp\htdocs\[folder-name]\
   □ All files are present in the folder

□ STEP 3: Start Services
   □ Opened XAMPP Control Panel
   □ Started Apache (shows green "Running")
   □ Started MySQL (shows green "Running")
   □ No port conflicts (80, 443, 3306)

□ STEP 4: Database Setup
   □ Opened http://localhost/phpmyadmin
   □ Clicked "Import" tab
   □ Selected database.sql file
   □ Clicked "Go" and saw success message
   □ Database "inventory_db" appears in left sidebar
   □ Tables "users" and "products" exist

□ STEP 5: Test Connection
   □ Opened http://localhost/[folder-name]/test_connection.php
   □ All tests show green "OK" status
   □ Database connection successful
   □ Both tables exist

□ STEP 6: Access Application
   □ Opened http://localhost/[folder-name]/
   □ Redirected to login page
   □ Page loads without errors

□ STEP 7: Register Account
   □ Clicked "Register here" link
   □ Filled in username, email, password
   □ Registration successful
   □ Received success message

□ STEP 8: Login
   □ Entered email and password
   □ Login successful
   □ Redirected to dashboard
   □ Can see welcome message with username

□ STEP 9: Test Features
   □ Dashboard shows statistics
   □ Can navigate to "View Products"
   □ Can navigate to "Add Product"
   □ Can add a new product
   □ Product appears in products list
   □ Can edit a product
   □ Can delete a product
   □ Can logout successfully

□ STEP 10: Cleanup (Optional)
   □ Deleted test_connection.php file
   □ Deleted SETUP_CHECKLIST.txt file
   □ Application is ready to use!

========================================
COMMON ISSUES & SOLUTIONS
========================================

Issue: Apache won't start
□ Close Skype (uses port 80)
□ Stop IIS if running
□ Change Apache port in XAMPP config
□ Check Windows Firewall

Issue: MySQL won't start
□ Check if another MySQL is running
□ Stop MySQL Windows service
□ Change MySQL port in XAMPP config
□ Check Task Manager for mysqld.exe

Issue: Page shows "Connection failed"
□ Verify MySQL is running (green)
□ Check config/db.php settings
□ Verify database name is "inventory_db"
□ Username should be "root"
□ Password should be empty

Issue: Page shows "Database not found"
□ Import database.sql in phpMyAdmin
□ Check database name spelling
□ Refresh phpMyAdmin page

Issue: Blank white page
□ Check Apache error logs
□ Enable display_errors in php.ini
□ Check file permissions
□ Look for PHP syntax errors

Issue: 404 Not Found
□ Verify project is in htdocs folder
□ Check URL spelling
□ Verify Apache is running
□ Try http://localhost/ first
