🔧 TROUBLESHOOTING:

Problem: PHPMailer installation fails
Solution: 
   - Check internet connection
   - Try again
   - Or use development mode (OTP on screen)

Problem: Email not received
Solution:
   - Check spam folder
   - Wait 1-2 minutes
   - Try test_email.php first
   - Check internet connection

Problem: SMTP error
Solution:
   - Check firewall settings
   - Temporarily disable antivirus
   - System will show OTP on screen as fallback
